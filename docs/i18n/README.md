## ✍️ How to Add a New Translation

1. Fork the repository on GitHub.
2. Copy `docs/USER_MANUAL.md` to `docs/i18n/USER_MANUAL.<language-code>.md` (e.g. `docs/i18n/USER_MANUAL.fr.md` for French).
3. Translate all sections accurately while preserving Markdown link structures and code examples.
4. Add your language to the table above.
5. Open a Pull Request with title `docs(i18n): add <Language> translation for user manual`.
